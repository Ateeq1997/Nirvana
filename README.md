# Nirwana – Product Visualization Website

**Nirwana** is a modern product visualization website built with **React and TypeScript**, focused on presenting **marble slabs and wooden tiles** in realistic interior environments. The project emphasizes clean UI, smooth user experience, and practical visualization for material selection.

---

## Project Overview

Nirwana is designed to help users explore surface materials by visualizing them in everyday living spaces. The goal is to make product comparison easier and more engaging through realistic presentation.

**Visualize Materials with Confidence**

---

## Interior Spaces

### Living Area
Showcases how marble and wood surfaces contribute to a refined and welcoming living environment.

### Bedroom Space
Highlights calm and comfortable designs, helping users imagine materials in personal and relaxing spaces.

### Workspace / Office
Focused on functionality and modern design, presenting surfaces suitable for productive work environments.

---
The website supports **four languages**:

- **English**
- **Spanish**
- **Italian**
- **French**

When a user selects a language, the **entire website content updates dynamically** to the selected language, providing a localized and user-friendly experience.
